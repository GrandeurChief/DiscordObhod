> Этот инструмент применяют как легитимные, так и вредоносные программы, однако сам он вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Ряд антивирусов классифицирует файлы WinDivert как инструменты для взлома или объекты повышенного риска, после чего удаляет их либо отправляет в карантин. Название такого обнаружения обязательно содержит `WinDivert` или выглядит как `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог с zapret в исключения антивируса или выключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky предусмотрен пункт «Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда». Если умеете корректно настраивать исключения, используйте их; если не вполне понимаете свои действия, лучше отключите обнаружение PUA.

## ⚙️Порядок использования

1. Активируйте Безопасный DNS (Secure DNS)
    * В Chrome включите «Использовать безопасный DNS» и укажите поставщика DNS, отличного от варианта «Поставщик по умолчанию»
    * В Firefox откройте «DNS через HTTPS», установите режим «Персональный», затем нажмите «Выбрать провайдера/поставщика» и вручную укажите URL. Подойдёт, например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет активировать Secure DNS непосредственно в параметрах системы — [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Этот способ рекомендуется пользователям Windows 11
    * Владельцам роутеров Keenetic нужно включить параметр «Транзит запросов». Если он отключён, при настройке и работе Secure DNS на компьютере возможны проблемы

2. Загрузите архив zip/rar со [страницы актуального релиза](https://github.com/GrandeurChief/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и отметьте «Разблокировать». При использовании 7-Zip или PeaZip выполнять этот шаг не требуется

4. Извлеките архив в каталог, путь к которому не включает кириллицу и специальные символы

5. Откройте подходящий файл
    * Найти рабочую стратегию: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Настроить автозапуск: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Что делают файлы

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Ручной режим предназначен для проверки стратегий. Их работоспособность определяется множеством факторов. **Перебирайте разные варианты — ALT, FAKE и остальные, — пока не найдёте подходящее вам решение**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные возможности:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск через services.msc</ins>
  - **`Remove Services`** — удаление WinDivert и стратегии из списка служб
  - **`Check Status`** — просмотр состояния обхода и служб: WinDivert и запущенной автоматически стратегии
  - **`Game Filter`** — смена режима обхода для игр и прочих сервисов, работающих по UDP и TCP на портах выше 1023.  
  **Чтобы применить переключение, перезапустите стратегию.**  
  Текущее состояние — включено или выключено — отображается в скобках.
  - **`IPSet Filter`** — выбор режима обхода для сервисов, перечисленных в `ipset-all.txt`.  
  Пригодится во время тестирования, когда ресурс доступен без zapret, но не работает с ним.  
  В скобках показывается активный режим:
    - `none` — IP-адреса не проверяются
    - `loaded` — проверяется присутствие IP-адреса в списке
    - `any` — фильтрация применяется к любому IP-адресу  
  - **`Auto-Update Check`** — включение или отключение автоматического поиска обновлений
  - **`Replace active fakes`** — замена указанного активного фейка другим файлом из каталога `bin`
  - **`Update IPSet List`** — загрузка актуальной версии списка `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — поиск доступных обновлений
  - **`Run Diagnostics`** — поиск распространённых причин, мешающих работе zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`: это иногда помогает, когда приложение внезапно перестаёт работать
  - **`Run Tests`** — запуск инструмента, проверяющего работоспособность стратегий:
    - `Standard tests` — тестирование сайтов, перечисленных в `utils/targets.txt`
    - `DPI checkers` — проверка DPI через разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неполадки

### При запуске скрипта `general*` ничего не меняется

- Если стратегия запущена отдельным bat-файлом, а не через service, в панели задач должен появиться winws.exe, выполняющий обход.  
Если процесс не появился, обратитесь к [#522](https://github.com/GrandeurChief/zapret-discord-youtube/issues/522)

### Не удаётся подобрать рабочую стратегию
- Откройте командную строку с правами администратора
- По очереди выполните в консоли следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Выполните перезагрузку компьютера

### Веб-версия Telegram не открывается
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Выделите и скопируйте весь текст из открывшегося Блокнота
  - В появившейся папке откройте файл `hosts` текстовым редактором, запущенным от администратора
  - Вставьте скопированные строки в конец `hosts` либо замените прежний аналогичный блок
  - Сохраните изменения и снова проверьте соединение. Если результата нет, удостоверьтесь, что `hosts` действительно был сохранён.

#### Результат не гарантируется. Если способ не сработал, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/GrandeurChief/tg-ws-proxy) или любым публичным прокси.

### Обход перестал работать или не работал изначально

> [!IMPORTANT]
> **Любая стратегия со временем может утратить работоспособность.**
> Даже если конкретный вариант некоторое время работает, позднее его могут обнаружить, после чего он перестанет помогать.
> В репозитории собрано много стратегий обхода. Когда ни одна не подходит, создайте собственную на базе одного из имеющихся вариантов, изменив его параметры.
> Описание параметров стратегий доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и убедитесь в отсутствии ошибок

- Проверьте, присутствует ли адрес нужного ресурса в списке доменов либо IP

- Переберите остальные стратегии, включая **`ALT`**, **`FAKE`** и другие

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация приведена в [#765](https://github.com/GrandeurChief/zapret-discord-youtube/issues/765)

### Как выполнить полное обновление или переустановку?
- Сначала сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Выполните `service.bat` -> `Run Diagnostics`, устраните найденные ошибки и в конце нажмите Y
- Удалите каталог с zapret
- Загрузите свежую версию [на странице релизов](https://github.com/GrandeurChief/zapret-discord-youtube/releases), выбрав архив `zapret-discord-youtube-...`
- Щёлкните архив правой кнопкой и откройте свойства. Если справа внизу доступен пункт «Разблокировать», отметьте его, затем нажмите «Применить» и «ОК»
- Извлеките файлы в новый каталог в корне диска, исключив из пути пробелы и специальные символы
- Запускайте разные скрипты `general`, то есть стратегии, и проверяйте доступность интернет-ресурсов. Если они не открываются, закройте программу через значок замка на панели задач и испытайте следующий вариант
- Найдя рабочую стратегию, добавьте её в автозапуск через `service.bat` -> `Install Service` -> выберите нужный вариант

### При активном zapret перестаёт работать игра или приложение

- Удостоверьтесь, что в service.bat для `Game Filter` установлено **`disabled`**, а для `IPSet Filter` — **`none`**. Другие значения могут неожиданно ограничить доступ к ресурсам.

### Античит обнаруживает WinDivert

- Следуйте инструкции по адресу https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) служба WinDivert не исчезает

1. В командной строке Windows, открытой через Win+R и `cmd`, определите название службы командой:

```cmd
driverquery | find "Divert"
```

2. Завершите работу службы и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Выключите блокировщик рекламы: известно, что YouTube начал противодействовать таким расширениям.
- Переберите остальные стратегии, особенно если прежняя недавно перестала работать.
- Дополнительные сведения есть в [#251](https://github.com/GrandeurChief/zapret-discord-youtube/discussions/251)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Сначала желательно определить стратегию, с которой открывается YouTube, и запустить именно её.
- Откройте `service.bat` -> `Run Diagnostics` и воспользуйтесь функцией очистки кэша Discord.
- Запустите приложение Discord и проверьте, помогло ли удаление кэша.
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, можно пользоваться ей.
- Когда Discord не загружается и в браузере, повторно проверьте все стратегии. Иногда YouTube работает с определённой стратегией, а Discord — нет.
- Больше информации доступно в [#252](https://github.com/GrandeurChief/zapret-discord-youtube/discussions/252)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь приложением [tg-ws-proxy](https://github.com/GrandeurChief/tg-ws-proxy)
- Другой вариант — бесплатные публичные MTProto-прокси из интернета

### Не запускаются игры

Игр слишком много, поэтому исследовать и исправлять работу каждой невозможно.

Наиболее универсальная последовательность действий:
- обновите ipset через `service.bat`, затем активируйте `Game Filter`
- если результата нет, дополнительно попробуйте режим `ipset any`

Учитывайте, что `ipset any` может нарушить доступ ко многим сайтам, поэтому не оставляйте этот режим включённым постоянно. Чтобы обойтись без него, определите все IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`

Если эти действия тоже не помогли, создайте тему в разделе [Discussions](https://github.com/GrandeurChief/zapret-discord-youtube/discussions), а не в issues, и дождитесь ответа других игроков.

## 🗒️Как добавить адреса других ресурсов

Перечень адресов для обхода расширяется через следующие файлы:
- **`list-general-user.txt`** — домены, включая автоматически учитываемые поддомены
- **`list-exclude-user.txt`** — исключённые домены, например конкретный домен из сети, чей IP внесён в `ipset-all.txt`, но не должен фильтроваться
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — исключения для IP-адресов и подсетей
  - Файлы вида **`*-user.txt`** будут созданы автоматически при первом запуске `zapret` либо `service.bat`
